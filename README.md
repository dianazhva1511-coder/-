# Кошелёк

Личный учёт расходов для Android (проверялся с расчётом на Samsung Galaxy S24 Ultra).
Сам добавляет поступления и списания из уведомлений **Kaspi, Halyk, Forte** и **Samsung Wallet (Samsung Pay)**,
показывает графики расходов по дням, категориям и банкам. Все данные хранятся только на телефоне:
у приложения даже нет разрешения на интернет.

## Как это работает

1. Банк присылает уведомление: «Покупка 5 400 ₸ в MAGNUM. Доступно 120 000 ₸».
2. Приложение (через системный «Доступ к уведомлениям») видит только уведомления банков
   и Samsung Wallet, а также SMS от банков. Остальные уведомления пропускаются и не сохраняются.
3. Из текста берётся сумма (баланс «Доступно/Остаток» игнорируется), тип операции
   (покупка, оплата, перевод, снятие это расход; поступление, зачисление, возврат это доход), магазин и категория.
4. При оплате через Samsung Pay приходят два уведомления: от Wallet и от банка. Они склеиваются
   в одну операцию с пометкой «Kaspi · Samsung Pay», поэтому расход не задваивается.
5. Коды подтверждения и рекламные сообщения пропускаются.

## Экраны

* **Обзор**: поступления, расходы и итог за месяц, график расходов по дням, категории в процентах, суммы по банкам.
* **Операции**: список по дням, добавление вручную («+»), правка категории и удаление по нажатию.
* **Журнал**: все уведомления банков и что с ними сделано. Нераспознанные можно скопировать и прислать, чтобы научить приложение.
* **Настройки**: включение доступа к уведомлениям, батарея, проверка распознавания на своём тексте.

## Установка на телефон

1. Скачайте файл `Koshelek.apk` на телефон (ссылку даст Claude, либо раздел **Releases** репозитория на GitHub).
2. Откройте файл. Samsung спросит, разрешить ли установку из этого источника: нажмите
   **Настройки → Разрешить из этого источника**, вернитесь и нажмите **Установить**.
   Если появится Play Защита, выберите **Подробнее → Всё равно установить**.
3. Откройте «Кошелёк» → вкладка **Настройки** → **Открыть настройки уведомлений** → включите «Кошелёк».
   Если переключатель серый: **Настройки телефона → Приложения → Кошелёк → ⋮ → Разрешить ограниченные настройки**, затем снова включите.
4. Там же нажмите **Открыть настройки приложения → Аккумулятор → Без ограничений**, чтобы Samsung не усыплял приложение.
5. Проверьте, что в Kaspi, Halyk, Forte и Samsung Wallet включены push-уведомления об операциях.

Операции, сделанные до установки, не подтянутся: приложение видит только новые уведомления.

## Для разработчика

* Kotlin, Jetpack Compose (Material 3), Room. minSdk 26, targetSdk 35.
* Распознавание: `app/src/main/java/kz/koshelek/app/parser/NotificationParser.kt`, тесты рядом в `app/src/test`.
* Сборка: `./gradlew assembleRelease` (нужен Android SDK) или GitHub Actions (`.github/workflows/build-apk.yml`), который сам публикует APK в Releases.
